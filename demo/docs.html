Touch interactions,
made predictable.

finger-gestures gives your web interface a small, typed vocabulary for multi-finger taps and four-way swipes. It works with any element that receives Pointer Events.

Quick start

Install the package, then pass an element and the gestures you want to recognise. 

npm install finger-gestures
import { fingerGestures } from 'finger-gestures'

const stop = fingerGestures(canvas, {
  tap: {
    2: () => undo(),
    3: () => redo(),
  },
  swipe: {
    3: { up: openMenu, down: closeMenu },
  },
})

// Remove listeners when the interaction ends.
stop()

Set captureTouch: false when the element should keep its normal scrolling and zooming behaviour.

Handlers

Tap handlers are keyed by finger count. Swipe handlers can be a single function, or an object with a function for each direction. 

fingerGestures(element, {
  tap: { 1: onTap, 2: onUndo },
  swipe: {
    2: (event) => console.log(event.direction),
    3: { left: goBack, right: goForward },
  },
}, options)

Every handler receives an event with the finger count, timing, position, and original pointer event. Swipe events also include direction, distance, velocity, dx, and dy.

Options

Option Default Purpose
joinMs 180 Max time between fingers landing
tapMaxMs 350 Maximum tap duration
tapSlop 14 Maximum movement for a tap, in pixels
swipeMinDistance 48 Minimum average swipe distance
swipeMaxMs 800 Maximum swipe duration

Recognition model

A gesture begins with the first finger and resolves when the last finger lifts. Fingers must join within joinMs. Small movement becomes a tap; clear, mostly one-axis movement becomes a swipe.

Pinches, rotations, diagonals, scattered movement, late fingers, and system-reserved gestures are rejected. Use onReject while tuning to see exactly why an input was ignored.
