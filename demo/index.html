Install

Add the package to your project.

$ npm install finger-gestures

Usage

Pass an element and the gestures you want to handle.

import { fingerGestures } from 'finger-gestures'

const canvas = document.querySelector('canvas')

// 2-finger tap undoes, 3-finger tap redoes
const stop = fingerGestures(canvas, {
  tap: { 2: undo, 3: redo },
  swipe: { 3: { up: openMenu, down: closeMenu } },
})

// remove the listeners when you're done
stop()
  • Pass any element that should receive gestures.
  • Register only the finger counts and directions you need.
  • Call stop() when the interaction ends.

What it recognises

Taps with any number of fingers, and up, down, left or right swipes. Fingers must land close together, move together, and travel mostly along one axis. Pinches, rotations, diagonals and system-reserved gestures are rejected rather than guessed.

Use onReject to see why a gesture was ignored while you tune, and captureTouch to control whether the browser can scroll or zoom on your element.
